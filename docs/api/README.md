# Local API contracts

The checked-in files in this directory are generated by `repolens api export` from the
same FastAPI application used by `repolens serve`:

- `openapi.json` — OpenAPI 3 schema consumed by Swagger UI/ReDoc and other clients.
- `repository-lens.postman_collection.json` — requests ordered as health, capabilities,
  scan, read, query and report.
- `local.postman_environment.json` — loopback base URL and an empty secret token value.

From the repository root:

```bash
python -m pip install -e '.[stack,api]'
repolens api export --out docs/api
```

Start the API separately with a token of at least 32 characters:

```bash
export REPOLENS_API_TOKEN="$(python -c 'import secrets; print(secrets.token_urlsafe(32))')"
repolens serve
```

Import the collection and environment into Postman, set `api_token`, and run the
requests in order. The service is loopback-only and scans the checkout chosen by the
operator at startup; requests cannot choose paths, commands, repository URLs or
plugins. Restarting the process clears the in-memory latest analysis.
